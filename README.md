# NECC Flappy Bird
This is a Python game for programming students to contribute to and learn more about Python and GitHub collaboration.

## Requirements

- Python 3.10 or newer
- [pygame-ce](https://pyga.me/)

Install the dependency:

```powershell
python -m pip install -r requirements.txt
```

## Run

From the repository root:

```powershell
python Py-Flappy-Bird\main.py
```

Press **Space** or click to flap. Press **R** to restart after a game over, or **Esc** to exit.

## Tests

```powershell
python -m unittest discover -s Py-Flappy-Bird\tests -v
```
